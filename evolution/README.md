# Эволюция · localhost

Локальная многопользовательская адаптация «Эволюции: Происхождение видов». Русский интерфейс, комнаты, закрытые руки, боты, сохранение, атлас карт, дополнения, анимации и история популяций.

## Запуск

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
cd /Users/ekotov/AI/evolution
npm start
```

Открыть [http://localhost:3000](http://localhost:3000). Для другого порта: `PORT=3001 npm start`. Для разработки с перезапуском сервера: `npm run dev`.

## Несколько игроков

1. Первый участник нажимает «Создать игру», вводит имя, выбирает дополнения.
2. Остальные открывают новую вкладку/другой браузер на том же localhost и нажимают «Войти по коду».
3. Введите шестизначный код комнаты. Каждая независимая вкладка получает свою руку.
4. Создатель может добавить ботов и начать партию. На главной есть быстрая пробная партия с двумя ботами.

Для 5–6 участников включите «Время летать» либо второй комплект; для 7–8 — второй комплект. При выборе «Континентов» стартовая рука составляет 10 карт, иначе 6.

По умолчанию сервер доступен только на этом компьютере. Если вы сами хотите играть с нескольких устройств в одной локальной сети, запустите `HOST=0.0.0.0 npm start`; остальные откроют `http://ЛОКАЛЬНЫЙ_IP_ЭТОГО_КОМПЬЮТЕРА:3000`. `localhost` другого устройства означает уже то другое устройство.

## Лобби и игра за одним столом

В создании выберите режим:

- **Лобби · отдельные устройства**: открытое показывается в разделе «Лобби», закрытое доступно по ID или логину и паролю. Пароль хранится как scrypt-хеш с индивидуальной солью. Участники подключаются к одному локальному серверу.
- **За одним столом · один экран**: имена людей задаются в слотах, подключаться отдельно не нужно. Между очередями разных людей появляется экран «Передайте устройство»; рука показывается после нажатия кнопки. Пока ходит бот, его рука скрыта.

Доступно до восьми слотов: **Человек**, **Бот**, **Закрыт**. В сетевом лобби человеческий слот ждёт подключения; в игре за одним экраном это местный участник. Создатель может менять типы слотов и имена до старта. Чтобы начать, заполните все человеческие слоты или замените их ботами / закройте.

В активной игре за одним столом откройте **«Участники · человек ↔ бот»** (эта кнопка есть и на экране передачи устройства). Измените управление и нажмите **«Применить»**. Замена работает и в текущую очередь, сохраняет все карты, популяцию, очки и позицию игрока. После обратной замены человек продолжит с состояния, до которого доиграл бот. Создатель сохраняет управление столом, даже если его собственный слот занят ботом.

В разделе **«Лобби»** есть поиск открытых комнат по названию/ID, обновление списка, случайное подключение и вход по **ID или логину + паролю**. В случайном подборе участвуют только открытые сетевые лобби с вакантными человеческими слотами. Старые комнаты не попадают в открытый список, но сохраняют прежние ID и сессии.

Текущий проверочный запуск: [http://localhost:3001](http://localhost:3001), поскольку порт 3000 занят другим проектом. Команда: `PORT=3001 npm start`.

## Игра

- В развитии нажмите карту из руки, затем выберите «Создать животное» или свойство и цель. Каждое действие передаёт очередь следующему участнику.
- В питании нажмите своё животное. Панель показывает только допустимые действия.
- После основного действия можно применить дополнительные способности, затем нужно завершить очередь.
- При атаке решение о защите принимает владелец жертвы, а не нападающий.
- При получении еды связанные свойства могут открыть отдельную панель выбора. Завершите цепочку, чтобы продолжить игру.
- Комната сохраняется автоматически. Перезагрузка своей вкладки восстанавливает то же место. Не очищайте её sessionStorage, если хотите сохранить вход в эту комнату.

## Точность правил

Это рабочая адаптация; дополнения имеют экспериментальный статус. Точный базовый состав, дополнительные свойства, локации, растения и эффекты флоры реализованы. Однако полная эквивалентность настольной игре для всех комбинаций не подтверждена: есть реконструированный состав флоры и несколько ограничений порядка эффектов.

Подробный [план, источники и ограничения](PLAN.md), [реестр всех карт](research/CARD-REGISTER.md), [исследование дополнений](research/EXPANSIONS.md). Эти сведения также доступны в интерфейсе через значок ДНК слева.

npm run test:campaign

Движок и HTTP-сервер не используют внешних зависимостей. Все иконки лежат в `public/assets`; для игры интернет не нужен. Иконки предоставлены авторами Game-icons.net по CC BY 3.0; авторство указано в интерфейсе и `credits.json`.

## Хранение

Состояние комнат хранится локально в `.data/rooms.json`, включая скрытые карты и ключи входа. Каталог исключён из Git и недоступен по HTTP. Сервер сохраняет файл атомарно через временный файл. Ctrl+C завершает сервер.

Авторы оригинальной настольной игры: Дмитрий Кнорре и Сергей Мачин. Издатель: «Правильные игры». Этот проект — независимая цифровая адаптация.
