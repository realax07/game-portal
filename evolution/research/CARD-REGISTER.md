## Происхождение видов

|---|---:|---|---|
| Хищник | 1 | attack | Вместо красной еды атакует другое животное. Успех приносит 2 синие фишки. Одна атака за ход; нельзя сочетать с падальщиком. |
| Жировой запас | 0 | food | Каждая копия хранит одну жёлтую фишку. Сытое животное запасает полученную еду; жир сохраняется между ходами и может стать синей едой. |
| Водоплавающее | 0 | defense | Атака возможна только между двумя водоплавающими или двумя сухопутными животными. С Континентами отправляет в Океан и сбрасывается. |
| Большой | 1 | defense | Атаковать это животное может только большой хищник. Потребность в еде увеличена на 1. |
| Быстрое | 0 | defense | При атаке бросается кубик: 4–6 спасают животное. Бросок обязателен, даже при атаке своего животного. |
| Ядовитое | 0 | defense | Съевший животное хищник погибает в фазу вымирания. Отброшенный хвост не отравляет. |
| Камуфляж | 0 | defense | Защищает от атаки хищников без острого зрения. |
| Острое зрение | 0 | attack | Позволяет хищнику атаковать камуфлированную добычу. |
| Норное | 0 | defense | Накормленное животное нельзя атаковать. Непреобразованный жир сам по себе не даёт сытость. |
| Отбрасывание хвоста | 0 | defense | В ответ на атаку сбрасывает выбранное свойство, кроме несбрасываемого. Животное живёт, хищник получает 1 синюю еду. |
| Мимикрия | 0 | defense | Первую атаку за ход перенаправляет на другое своё животное, доступное этому хищнику. Владелец выбирает жертву. |
| Падальщик | 0 | food | После успешного поедания 1 синюю еду получает один падальщик: сначала у владельца хищника, затем по кругу. Несовместим с хищником. |
| Паразит | 2 | negative | Играется только на чужое животное. Увеличивает потребность в еде на 2. Можно сбросить при отбрасывании хвоста. |
| Пиратство | 0 | food | Раз за ход крадёт 1 красную или синюю еду у ненакормленного животного. Дополнительное действие в свою очередь питания. |
| Взаимодействие | 0 | pair | Связь двух своих животных: когда одно получает красную еду, второе берёт красную из той же кормовой базы. Каждая связь срабатывает один раз в очередь. |
| Сотрудничество | 0 | pair | Когда одно животное пары получает красную или синюю еду, второе получает 1 синюю. Каждая связь срабатывает один раз в очередь. |
| Симбиоз | 0 | pair | Первое выбранное животное — симбионт. Второе защищено от хищников, пока симбионт жив, и может есть только после насыщения симбионта. |
| Спячка | 0 | food | Считает животное накормленным. Не работает два хода подряд и в последний ход. В спячке нельзя получать еду, в том числе запасать жир. |
| Топотун | 0 | food | Дополнительно в каждую свою очередь питания уничтожает одну красную фишку в своей локации. |

## Время летать

| Свойство | Еда + | Тип | Реализуемая механика |
|---|---:|---|---|
| Полёт | 0 | defense | Хищник не может атаковать, если у него столько же или больше свойств, чем у жертвы. С Континентами 1–2 свойства позволяют перелетать между материками. |
| Интеллект | 0 | attack | Один раз за ход позволяет игнорировать одно выбранное свойство жертвы до конца хода. Не отменяет удильщика и убежища. |
| Живорождение | 1 | food | Став накормленным, рождает животное с верха колоды. Новорождённое уже накормлено и появляется в локации родителя. |
| Засада | 0 | attack | Хищник может атаковать вне очереди животное, берущее красную еду. При успехе еда остаётся на месте; нора и раковина не защищают. |
| Раковина | 0 | defense | При атаке можно закрыться до конца хода: нельзя получать еду, кроме преобразования жира. После смерти раковина остаётся на столе и может быть занята. |
| Чернильное облако | 0 | defense | Один раз за ход отменяет атаку. Хищник сможет повторить её в свою следующую очередь этого хода. |
| Метаморфоза | 0 | food | Вместо основной еды сбрасывает выбранное свойство без прибавки к потребности и получает 1 синюю еду. Можно сбросить саму метаморфозу. |
| Специализация A | 0 | food | Вместо основной еды получает 1 синюю, если нет другого животного с такой специализацией. С Континентами типы A/B объединяются внутри локации. |
| Специализация B | 0 | food | Аналог специализации A для другой экологической ниши. Одно животное не может иметь сразу оба типа. |
| Трематода | 1 | pair | Негативная парная карта на двух животных одного соперника; каждому +1 к еде. Нельзя сбросить свойством другой карты, кроме иммунитета. |
| Удильщик | 0 | special | Играется как скрытое животное. При атаке простого животного владельца может вскрыться и атаковать напавшего, игнорируя одно свойство. |

## Флора: 12 эффектов

Тираж реконструирован: по 2 копии; требует сверки по физическим картам.

- **Бледная поганка**: Даёт метку Яд и сбрасывает паразитов. Без Антидота носитель погибнет в вымирание.
- **Плесневый гриб**: Антидот защищает от Яда и отравления ядовитой добычей.
- **Безумная шляпка**: Следующую очередь питания за вас проводит сосед справа, не видя вашу руку.
- **Бешеный мухомор**: Вместо следующей очереди принудительная атака: жертва погибает, но еды атакующий не получает.
- **Гриб прозрения**: Сбросьте руку. Посмотрите руку соперника, верх одной колоды или скрытую карту животного.
- **Окрыляющий гриб**: Сбросьте все парные свойства животного и получите дополнительную синюю еду.
- **Сон-трава**: Отключает все свойства животного до конца хода. Потребность в еде становится равна 1.
- **Трын-трава**: Предотвращает получение новых меток последствий.
- **Дурман-трава**: Нападающий хищник может игнорировать одно свойство этого животного.
- **Улыбнись-трава**: Запрещает животному нападать и использовать Пиратство.
- **Очистительная трава**: Убирает всю еду, кроме только что полученной красной, и все метки последствий.
- **Страстоцвет**: Превратите одно своё свойство, кроме паразита, в новое животное.
