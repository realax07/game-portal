# Аудит игровых карт

Это проверка игровых определений и колод, без учёта изображений. Пересобрать: `npm run cards:audit`. Проверить актуальность: `npm run cards:check`.

## Результат

- 413 игровых определений / 407 уникальное название в 62 выбираемых наборах. **800+ реализованных карт нет.**
- Все определения выбранных наборов попадают в партию; сыгранные мгновенные карты учитываются в сбросах и ожидающих решениях. При выборе всех наборов: 447 экземпляров из 413 определений. Отсутствующих игровых ID: 0.
- Искусственные множители ×5/×6 убраны из новых партий. Для исходных трёх наборов используются печатные количества уже реализованных карт; для непроверенных дополнений — один экземпляр каждого определения. Состав пока неполный.
- Правила: 23 с существующей отметкой сверки, 132 частичных, 204 непроверенных, 54 без статуса. Сверка метаданных не доказывает полноту реализации всех эффектов.
- Списки 49 наборов содержат 1487 разных названий / 1590 вхождений «набор + название + раздел». 1225 вхождений отсутствуют в соответствующем игровом наборе; 1127 названий не заведены ни в одном наборе. У остальных 13 наборов полный состав ещё не подтверждён.

## Исходные коробки

У издателя база содержит 168 экземпляров (95 дверей + 73 сокровища), дополнения 2 и 3 — по 112. Вместе 392 экземпляра. В игре — 164 определений, составляющих 198 экземпляров. Базовая универсальная «Go Up a Level» не совпадает с отдельными печатными картами повышения уровня.

База содержит все 147 уникальных названий и 168 печатных экземпляров: 95 дверей + 73 сокровища. Мгновенные эффекты раздачи учитываются в руках, сбросах и ожидающих решениях, а не теряются при аудите. Старые сохранения сохраняют прежнее количество карт; миграция обновляет метаданные, но не порядок и состав колод.

## Найденные пробелы эффектов

- Статусы каждого монстра перечислены в JSON-реестре. Число проверенных текстов и число работающих обработчиков — разные показатели.
- Базовые проклятия имеют индивидуальные обработчики, защиту кольцом/сандалиями, способность орка и сохраняемые выборы. Неподтверждённые проклятия дополнений остаются адаптациями.
- Все 6 подземелий превращены в события дверей с прибавкой к силе монстров. Отдельная колода и печатные правила подземелий не реализованы.
- У Манчкиномикона нет колоды заклинаний; Reloaded Die применяется только к смывке; ряд предметов сохраняет адаптированные параметры.
- Наличие обработчика типа карты и описания способности не является проверкой полного печатного текста.

## Машиночитаемый реестр

[Полный отчёт](../../public/data/gameplay-audit.json) содержит все отсутствующие названия, наборы, источники, статусы каждого игрового определения и количество экземпляров по каждому ID. [Списки исходных коробок](../core-publisher-lists.json) сохраняют печатные повторы. Старый [каталог дополнений](../../public/data/publisher-catalog.json) удалял повторные названия, поэтому не позволяет проверить точное количество экземпляров дополнений.

## Что требуется для полного каталога

1. Добавить отсутствующие игровые определения с проверенными параметрами, типами и текстами эффектов. Одних названий из списков недостаточно.
2. Дополнить индивидуальные эффекты существующих адаптаций; проверить отдельные колоды и специальные механики дополнений.
3. Дополнить печатное количество экземпляров всех дополнений; множители уже убраны из новых партий.
4. Проверить раздачу, исчерпание и перемешивание сброса, бои и поведение ботов на полном составе.

## Ограничения проверки

- Список издателя содержит названия, а не тексты правил. Наличие названия или изображения не означает реализацию.
- verified означает существующий статус сверенных метаданных; этот аудит не подтверждает полноту всех эффектов карты.
- not-classified означает отсутствие статуса проверки, а не отсутствие особенностей у печатной карты.
- В старом каталоге дополнений повторные названия удалены: число печатных экземпляров по нему восстановить нельзя.
- Для 13 наборов нет сохранённого полного списка. Общий список отсутствующих карт является нижней границей.
- Часть наборов имеет специальные колоды; упрощённое отнесение всех карт к дверям/сокровищам не проверено на соответствие оригиналу.
