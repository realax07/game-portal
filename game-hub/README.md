# Игровая

Локальный хаб для игр в соседних папках: Манчкин, Vice Drive, Velvet Poker, Танки против динозавров и Дурак. Использует существующие файлы игр, без установки зависимостей. В Манчкине внешние шрифты при отсутствии интернета заменяются системными.

## Запуск

```sh
cd game-portal/game-hub
npm start
```

Откройте http://localhost:8080. Нужен Node.js 18+. Другой порт: `PORT=8081 npm start`. Остановка: Ctrl+C.

Поиск по названию и описанию, фильтры жанров, избранное и недавние игры. Данные библиотеки сохраняются в браузере. Игры открываются внутри хаба, также доступны отдельная вкладка и полный экран. Возврат в библиотеку завершает текущую игру; игровые сохранения определяются самой игрой.

Сервер слушает только 127.0.0.1 и выдаёт файлы веб-интерфейса, разрешённые ресурсы игр и их превью. Список игр и пути к ним находятся в `server.mjs`. Исходные игры не изменяются.
