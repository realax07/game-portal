# Игровая

Локальный хаб для шести игр в соседних папках: Эволюция, Манчкин, Vice Drive, Velvet Poker, Танки против динозавров и Дурак. Использует актуальные файлы из `/Users/ekotov/AI`, без сборки и установки пакетов.

## Запуск и остановка всех сервисов

В домашней папке установлены два исполняемых файла. Их можно запускать двойным щелчком в Finder либо из терминала:

```sh
~/start-game-portal.command
~/stop-game-portal.command
```

Нужен Node.js 22 или новее. После запуска откройте http://localhost:8080. Сервисы работают в фоне после закрытия окна терминала. Повторный запуск не создаёт дубликатов. Повторная остановка допустима.

| Сервис | Порт |
| --- | --- |
| Хаб | 8080 |
| Дурак | 3000 |
| Эволюция | 3001 |
| Vice Drive | 4173 |
| Манчкин | 4387 |
| Velvet Poker | 5173 |
| Танки против динозавров | 8000 |

Все сервисы слушают только `127.0.0.1`. Хаб открывает игры с их отдельных портов внутри своего окна. Эволюция работает через собственный сервер: API комнат, SSE-события, боты и сохранения. Переносить её как обычную статическую страницу нельзя.

Скрипты в домашней папке вызывают `services.mjs`. Настройки портов и папок находятся в `services-config.mjs`. Журналы и сведения о запущенных процессах лежат в `.runtime/`. Остановка проверяет PID, время запуска и команду процесса и завершает только сервисы своего запуска. При занятом чужим процессом порте запуск прекращается с сообщением. При неудачном запуске уже поднятые этим вызовом сервисы останавливаются.

Состояние комнат Эволюции хранится в `../evolution/.data/`; при штатной остановке сервер завершает сохранение. Существующие сохранения не удаляются. Браузерные сохранения и избранное зависят от origin (адреса и порта); прежние сохранения игр внутри порта 8080 автоматически не переносятся на отдельные порты.

## Только хаб

```sh
cd /Users/ekotov/AI/game-hub
npm start
```

В таком режиме четыре статические игры доступны непосредственно через хаб; Манчкин требует отдельного сервера на 4387, а Эволюция — на 3001. Остановка запущенного вручную хаба — Ctrl+C. Домашний скрипт остановки не трогает серверы, запущенные вручную.

Поиск, фильтры жанров, избранное и недавние игры доступны в библиотеке. Возврат в библиотеку закрывает игру; возможность продолжения зависит от самой игры. Список игр и превью задаются в `server.mjs`. При отсутствии сети внешние шрифты заменяются системными.
