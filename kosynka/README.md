# ♠ Косынка

Классический пасьянс «Косынка» (Klondike) в браузере. Чистые HTML/CSS/JS, без зависимостей.

## Запуск

```bash
python3 -m http.server 8123
```

Открыть: http://localhost:8123

## Управление

- **Клик по колоде** — взять карту (или вернуть отбой в колоду, когда она пуста)
- **Перетаскивание** — перенос карт и последовательностей вручную
- **Клик по карте** — умный ход: сначала в «дом», затем на подходящую колонку
- **↩ Отменить / Ctrl+Z** — отмена ходов
- **Открывать: 1/3** — сколько карт брать из колоды за раз
- **Завершить ▸** — автосборка, когда все карты открыты
- **Заново** — та же раскладка с начала

Игра автоматически сохраняется в браузере — можно закрыть вкладку и продолжить позже.
Ведётся статистика: партии, победы, лучшее время и очки.
