# Дурак — карты на стол

Локальная браузерная игра в подкидного дурака на 36 карт против компьютера.

## Запуск

Нужен Node.js 18 или новее. Зависимостей нет.

```sh
npm start
```

Откройте http://localhost:3000. Для остановки сервера нажмите Ctrl+C.

## Игра

Нажимайте на подсвеченные карты. Если карта может побить несколько карт на столе, выберите цель. «Бито» завершает успешную защиту соперника; «Забрать карты» позволяет взять весь стол. После решения соперника взять карты можно подкинуть ещё и нажать «Завершить ход». Правила доступны в окне «Как играть».

Лимит атаки с первого раунда — 6 карт, но не больше числа карт защитника в начале раунда. Первым ходит обладатель младшего козыря; при отсутствии козырей у обоих первым ходит игрок. Компьютер видит только свои карты и открытый стол. Состояние хранится в памяти вкладки; обновление страницы начинает новую партию.

## Проверка

```sh
npm test
```

Проверки правил защиты и лимитов, а также 1000 автоматических партий с проверкой сохранности всех 36 карт и завершения игры.
