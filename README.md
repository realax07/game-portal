# Игровая — Game Portal

Единый локальный веб-хаб для семи браузерных игр. Поиск, фильтры по жанрам, избранное, недавние игры, запуск внутри портала, в отдельной вкладке и на весь экран.

## Запуск

Нужен Node.js 22 или новее. Устанавливать зависимости и собирать проект не требуется.

```sh
gh repo clone realax07/game-portal
cd game-portal
npm run services:start
```

Откройте [localhost:8080](http://localhost:8080). Все сервисы слушают только `127.0.0.1` и работают в фоне. Остановка всех сервисов: `npm run services:stop`. Повторный запуск не создаёт дубликатов.

## Игры

| Игра | Папка | Что внутри |
| --- | --- | --- |
| Косынка | `kosynka` | Пасьянс Klondike, отмена ходов, автосборка и сохранение |
| Эволюция | `evolution` | Комнаты для 2–8 игроков, боты, дополнения и серверные сохранения |
| Манчкин — Подземная таверна | `Manchkin/public` | Фэнтезийная карточная игра для 1–5 игроков, боты и игра за одним экраном |
| Vice Drive | `GTA/dist` | 3D-город, машины, погони и задания; нужен WebGL |
| Velvet Poker | `Poker/velvet-poker/dist` | Техасский холдем с ботами, обучение и виртуальные фишки |
| Танки против динозавров | `Tanks/tanki/dist` | Аркада с защитой штаба, бонусами и рекордами |
| Дурак | `Durak` | Подкидной дурак на 36 карт против компьютера |

Файлы `dist/` содержат сами игры и включены в репозиторий. Хаб использует их напрямую. Исходники, инструкции, имеющиеся тесты, превью и атрибуция иллюстраций сохранены в папках игр.

Избранное, недавние игры и поддерживаемые играми сохранения хранятся в браузере. Возврат в библиотеку закрывает текущую игру; восстановление партии зависит от самой игры. Сохранения с других localhost-портов автоматически не переносятся. При отсутствии интернета внешние шрифты Манчкина заменяются системными.

## Проверка

```sh
npm test
```

Запускает существующие проверки Дурака, Vice Drive, покерного движка, обучения покеру, Манчкина и Эволюции. У Танков отдельного автоматического набора тестов нет.

## Структура

`game-hub/server.mjs` обслуживает интерфейс, API каталога и ресурсы игр. `game-hub/public/` содержит веб-интерфейс. Список игр, пути к игровым файлам и превью задаются в массиве `games` в сервере; счётчики интерфейса вычисляются из каталога.

## Порты и отдельный запуск

Хаб — 8080; Косынка — 8123; Дурак — 3000; Эволюция — 3001; Vice Drive — 4173; Манчкин — 4387; покер — 5173; танки — 8000. Настройки находятся в `game-hub/services-config.mjs`. Журналы и PID-файлы сохраняются в `game-hub/.runtime/` и исключены из Git. При занятом чужим процессом порте запуск останавливается с сообщением.

`npm start` запускает только хаб в текущем терминале; пять статических игр доступны через него напрямую. Манчкин и Эволюция требуют собственных серверов: `npm start --prefix Manchkin` и `PORT=3001 npm start --prefix evolution`. Завершение запущенного в терминале сервера — Ctrl+C.

Скрипты в `game-hub/scripts/` также запускают и останавливают все сервисы из этой копии репозитория. Домашние скрипты на исходном компьютере используют соседние рабочие папки в `~/AI`. Сохранения Эволюции в `evolution/.data/` остаются локальными и не включаются в репозиторий.
