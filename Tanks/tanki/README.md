# Танки против динозавров

Браузерная аркада на HTML, CSS и JavaScript, без сборки и зависимостей.

Запуск: `python3 -m http.server 8000 --directory dist`, затем http://localhost:8000.
Также можно открыть `dist/index.html` напрямую.

Управление: WASD или стрелки — движение, пробел — стрельба, P/Escape — пауза, M — звук, Enter — старт. На телефоне доступны экранные кнопки.

Защищайте штаб от 20 динозавров на каждом уровне. Кирпич разрушается, бетон пробивается после бонуса-звезды, вода блокирует движение, кусты скрывают танки. Рапторы быстрые, тираннозавры выдерживают три попадания, трицератопсы — два. Динозавры не стреляют: преследуют танк, кусают вблизи, прогрызают кирпич и атакуют штаб. Бонусы дают усиление или жизнь. Рекорд сохраняется в браузере.
